## 一、产品定位（单点击穿）

只做一件事：**让"和 AI 说话"这件事像和人说话一样自然。**

- 开口即对话，不用按住说话
- AI 回答时，直接开口就能打断（全双工）
- 想打字就打字，想拍照就拍照，同一个输入坞

所有次要功能（学科系统、知识卡片、模型分析）保留在 `/tutor`，不进入主屏。

## 三、设计语言「墨夜 · 暖珀」

- **底色**：深墨暖黑（HSL 30 12% 6%），中央渐晕微亮、四角沉墨，叠加细颗粒质感
- **主角**：琥珀语音球，全屏唯一的彩色生命体
  - 待机 = 缓慢呼吸；连接 = 光晕旋转；聆听 = 涟漪随你的音量扩散；思考 = 内核收缩微光闪烁；回答 = 随语音脉动
- **字体**：标识用 Fraunces 衬线，正文走中文系统字体（苹方/思源黑体）
- **克制**：90% 墨色 + 10% 琥珀，颜色只给"活着"的东西

## 四、交互细节

- 轻触语音球开启会话；会话中麦克风常开，靠服务端 VAD 分轮
- AI 说话时点球体或直接开口 → 立即打断
- 底部输入坞一条胶囊：图片按钮 / 文字输入 / 麦克风按钮；输入文字时麦克风按钮自动变发送键
- 图片选择后先预览，可补一句问题再发送（自动压缩到 1280px）
- 设置做成底部抽屉，只有三项：API Key、模型模式、清除记录
- 全屏适配刘海屏安全区（safe-area-inset），禁用整页橡皮筋滚动

## 五、技术要点

- 新增 `StepFunRealtimeClient.sendText()`：文字消息走同一条 Realtime WebSocket 通道，AI 同样以语音+文字回复
- `lib/assistant/useAssistant.ts`：会话状态、麦克风管线、音量分析（写 ref 不触发渲染）、消息持久化（localStorage 最近 60 条）
- `lib/assistant/vision.ts`：图片问答调 step-1v-8k
- 麦克风音量通过 CSS 变量直接驱动球体缩放，绕过 React 渲染，保证 60fps
