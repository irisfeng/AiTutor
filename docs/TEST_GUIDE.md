## 〇、准备工作（只做一次，约 5 分钟）

### 前提

- 电脑装有 **Node.js 18+**（终端输入 `node -v` 能看到版本号即可）
- 装有 **git**（终端输入 `git -v` 验证）
- 手边有 **StepFun API Key**（[platform.stepfun.com](https://platform.stepfun.com) 获取）
- 浏览器用 **Chrome**

### 获取代码并启动

打开终端（Mac：`Cmd+空格` 搜"终端"），逐行粘贴执行：

```bash
cd ~/Desktop
git clone https://github.com/irisfeng/AiTutor.git
cd AiTutor
git checkout claude/mobile-ai-assistant-redesign-ggednq
cd web
npm install --legacy-peer-deps
npm run dev:all
```

> 已经克隆过的话，跳过 clone 那行，进入项目目录后执行
> `git fetch origin && git checkout claude/mobile-ai-assistant-redesign-ggednq && git pull`，
> 再 `cd web && npm install --legacy-peer-deps && npm run dev:all`。

**启动成功的标志**：终端出现 3003（页面）和 3004（语音代理）两个端口就绪的提示，且不再滚动报错。

### 打开页面

1. Chrome 访问 `http://localhost:3003`
2. 按 `Cmd+Option+I` 打开开发者工具 → 点左上角**手机图标** → 机型选 **iPhone 14 Pro**（目标体验尺寸）
3. 点右上角**滑块图标**打开设置 → 填入 API Key → 确认模型选中「**2.5 新模型**」→ 关闭设置

## 二、常见问题排查

| 现象 | 处理 |
|---|---|
| `npm install` 报错 | 确认带了 `--legacy-peer-deps` 参数 |
| 端口被占用（EADDRINUSE） | 终端执行 `lsof -ti:3003,3004 \| xargs kill` 后重新 `npm run dev:all` |
| 麦克风没反应 | 浏览器地址栏右侧检查麦克风权限；系统设置里确认 Chrome 有麦克风权限 |
| 连接失败 | 检查 API Key；确认终端里 3004 代理没报错；检查账户余额 |
| 有声音进不去文字 | 正常等 1~2 秒，转写完成才显示 |
